## 优惠码怎么用？续费会不会涨价？

使用步骤只有一步：选好套餐进入购物车，找到 Promotional Code 输入框，粘贴优惠码，点 Validate Code。页面刷新后如果单独列出了折扣金额，就生效了。

真正值得记住的是搬瓦工优惠码的“循环”属性。优惠码适用于购买、升级和续费，而且续费时系统会自动沿用你下单时用的码——第一次用了多少折扣，以后每次续费都是这个价格，直到你不再续费为止。这就是老用户宁可等大促的原因：在活动码有效期内下单，等于把 11% 左右的折扣锁进了之后每一年的账单。

输入后提示 The promotion code entered has expired，说明这个码已经彻底过期，不用再试第二次。当前这种没有常规码的时段，直接对比限量版补货和年付价格更实际。
